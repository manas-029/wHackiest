# LIFEGRAPH AI — Ideal Hackathon Demonstration

One fictional user with a college timetable, an approaching assignment deadline, pending tasks, personal interests, some free time and a limited monthly budget.

1. **Upload** the DBMS assignment PDF.
2. The AI **extracts** subject, questions, instructions and deadline; asks only for genuinely missing information such as current progress.
3. The system **creates a task** with estimated workload and priority.
4. The assistant checks the normal schedule and **identifies available time**.
5. The free-time optimizer **recommends working sessions** with breaks and personal time.
6. The user asks: *"What should I do this evening?"*
7. The assistant evaluates deadlines, priorities, preferences and time, then **recommends the best activity**.
8. The user **approves** the proposed schedule.
9. The system **creates calendar events and reminders**.
10. Task status and personal intelligence **update** as new information arrives.

## Talking points
- "Zero-input" means authorized automation, not unrestricted access.
- Recommendations are flexible, never fill every minute, and always editable.
- Cross-domain findings are presented as associations with confidence, never as diagnoses.
- The user controls memory, permissions and autonomy level.
