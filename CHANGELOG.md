# Changelog

All notable changes to the LIFEGRAPH AI pitch package are documented here.

## [1.0.0] — 2026-11-24

### Added
- 3-minute animated explainer video (1920×1080, 30 fps) with narration and soundtrack.
- Deterministic video renderer with 3D globe, extruded cards and perspective cycle ring.
- Four-colour client palette and cinematic motion system.
- Timed narration script, preview frames and generated audio tracks.
- Project documentation: product brief, architecture, demo script and video production guide.
- Repository-style files: README, changelog, license, ignore/format configs and launcher.

### Changed
- Opening 30 seconds rewritten to state the core idea and the real-world problem plainly.
- All assistant references generalized; spoken acronym spelled "A.I." for correct pronunciation.
- Narration re-synthesized per scene with fades to prevent abrupt cuts.

### Notes
- This is a hackathon pitch package; the video and docs describe the intended product.
- All example data shown in the video is synthetic.
